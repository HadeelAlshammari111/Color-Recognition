# Color Recognition Project

A computer vision project built using Python and OpenCV to detect and recognize colors in real-time through the webcam.

## Features
* Real-time video capture using OpenCV.
* Color space conversion for accurate color tracking.
* Interactive live window displaying the feed.
* Easy exit mechanism by pressing the q key.

## Technologies Used
* Python
* OpenCV
* NumPy

## Installation & Running

1. Clone the repository:
git clone https://github.com/HadeelAlshammari111/Color-Recognition.git

2. Navigate to the project directory:
cd Color-Recognition

3. Install the required dependencies:
pip install opencv-python numpy

4. Run the project:
python main.py
